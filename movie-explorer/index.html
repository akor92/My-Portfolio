Connect a TMDB API Key

CineVerse pulls live movie & drama data from TMDB. Get a free key, then paste it below — it's stored only in your browser (localStorage), never sent anywhere else.

  1. Create a free account at themoviedb.org/signup
  2. Go to Settings → API and request a "Developer" key
  3. Copy the "API Read Access Token" (v4 auth) or the v3 "API Key" and paste it here
